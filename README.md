# monportfolioSI

Portfolio Systèmes d'Information de Terrel Nuentsa. Les pages présentent les TDs, cours, et le projet final Bander-Sneakers avec aperçus plein écran des livrables (PDF, maquette, design system, guides, dump SQL/CSV).

## Structure
- `index.html` : page d’accueil (TDs, cours, projets, projet final).
- `td1.html` à `td4.html` : travaux dirigés avec aperçus PDF plein écran.
- `cours1.html` à `cours3.html` : supports de cours.
- `projet-bander.html` : détail du projet Bander-Sneakers (cahier des charges, rapport, maquette, design system, guides, SQL/CSV).
- `image/` : ressources (PDF, images, SQL/CSV).
- `style.css` / `main.js` : styles et interactions (modals plein écran, navigation, animations).

## Projet Bander-Sneakers
- **Démo** : https://bander-sneakers.kesug.com
- **Code** : https://github.com/binksterrel/bander-sneakers
- Livrables clés : cahier des charges, rapport, design system, maquette, guides (utilisateur/admin/installation), dump SQL/CSV.

## Utilisation
Ouvrez `index.html` dans un navigateur. Les boutons "Aperçu plein écran" ouvrent les PDF dans un modal; les téléchargements restent disponibles.

## Contribution
Cloner, ajuster le contenu ou les documents dans `image/` puis ouvrir `index.html`.
